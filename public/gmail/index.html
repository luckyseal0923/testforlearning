第一次使用：設定 Google 連線

先建立一次 Google OAuth Client ID。這是公開的應用識別碼；此頁不需要密鑰或 Gmail 密碼。

  1. 在 Google Cloud 建立或選擇專案，啟用 Gmail API。
  2. 開啟 Google Auth Platform，設定應用名稱與聯絡信箱。個人 Gmail 選 External，保留 Testing，並在 Audience 的 Test users 加入自己的 Gmail。
  3. 在 Data Access 加入 gmail.send 與 userinfo.email 對應的權限。
  4. 在 Clients 建立「Web application」。Authorized JavaScript origins 填下方網址，包含協定及主機，不加路徑。

使用彈出視窗授權，此範例不需要設定 Redirect URI。

只將 Client ID 記在此瀏覽器。設定好後，回到上方連接 Google 帳號。
