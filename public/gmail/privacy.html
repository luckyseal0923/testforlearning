資料與隱私說明

此網站是個人學習用的 Gmail API 範例，讓使用者連接自己的 Google 帳號，預覽並寄出單封純文字郵件。

使用哪些資料？

  • 電子郵件地址：顯示目前帳號並作為寄件者。
  • 寄信權限：在你按下「確認寄出」後，將收件者、主旨與內容交給 Gmail API 寄送。
  • 暫時的存取權杖：用於本次 Google API 請求；不讀取收件匣、信件內容或通訊錄。

資料存在哪裡？

信件內容、帳號與權杖只由目前頁面在記憶體中處理，不寫入本專案的伺服器、資料庫或瀏覽器儲存空間。重新整理或登出此頁後，本頁持有的授權會清除。

只有公開的 OAuth Client ID 會記在此瀏覽器的 localStorage，方便下次設定；可透過瀏覽器的網站資料設定移除。Client ID 不等於 Google 密碼或 Client Secret。

確認寄送後，郵件會交由 Google 處理，並依 Gmail 的機制保留在寄件者與收件者信箱。網站託管及 Google 登入服務可能依各自政策處理連線紀錄；本範例沒有額外加入分析工具。

如何停止使用？

按「登出此頁」清除本頁暫存授權。若要撤銷 Google 帳號對此應用的存取權，請至 Google 帳戶的第三方連線管理 移除對應應用。已寄出的郵件須在 Gmail 自行管理。

程式碼與問題回報：專案 GitHub 儲存庫。Google 的處理方式請參閱 Google 隱私權政策。
